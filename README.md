## 確認できたことと未確認事項

- GitHub 接続経由で、対象リポジトリの存在と読み取りアクセスを確認済みです。
- この Mac のローカル Git から HTTPS でリモート参照の問い合わせが成功し、その後、現在の作業フォルダへのクローンも成功しました。
- 読み取り確認は公開リポジトリに対して行いました。保存済み認証情報の有効性、SSH 接続、実際のプッシュの成功は未確認です。
- README と `.gitignore` の初期作成時点では、コミット・プッシュは行っていません。

## 記録とファイルの扱い

- 調査記録では、確認日時・確認方法・直接確認した事実・解釈・未確認事項を区別します。
- 認証情報を URL、文書、ログ、スクリーンショットに含めません。
- ローカル専用のメモや未整理の資料は `local/`、非公開資料は `private/`、生の調査ログやキャプチャは `captures/` など、`.gitignore` で除外した場所に置きます。これらのフォルダは現時点では作成していません。
- 共有する資料には必要な内容だけを整理し、認証情報や私的情報が含まれていないことを確認します。
- `.gitignore` は未追跡ファイルの誤追加を減らすための設定です。既に追跡されたファイルや、強制追加されたファイルを保護するものではありません。
- コミットやプッシュは、実行の依頼を受けてから行います。
